# lab-report：实验报告 skill

从三线摆与扭摆、示波器、透镜焦距和工程力学拉伸四类报告的终稿与修改要求中，提炼可复用的方法。

正文直接写事实、计算和结论，删除空话与防御型语言；按课程要求决定结构；保留必要推导；不改造原始数据；批注不越界；交付前检查计算与全部页面。

## 使用

安装后可直接提出实验报告任务，也可显式调用：

```text
使用 $lab-report，按指导书和我的原始数据完成报告。正文简洁，保留必要计算，交付 PDF 和可编辑源文件。
```

```text
使用 $lab-report，只检查报告是否符合所附指导书，不修改文件。先列真正影响提交的问题。
```

## 安装

将本仓库放入 Codex 的 skills 目录，并将文件夹命名为 `lab-report`，使入口位于 `~/.codex/skills/lab-report/SKILL.md`。也可让 Codex 从本仓库安装为 `lab-report`。

## 文件

- `SKILL.md`：任务范围、写作、计算、修改和交付规则。
- `references/writing.md`：通用删改示例和误差讨论方法。
- `references/cases.md`：四类实验的经验与适用边界。
- `agents/openai.yaml`：界面信息和默认调用提示。

仓库仅包含通用规则和匿名案例，不包含完整个人报告、身份信息、签字、照片、原始测量数据、本机路径或聊天记录。
