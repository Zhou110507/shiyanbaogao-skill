# 写作取舍与修改边界

这些规则归纳自物理与工程力学报告的最终写法和修改要求，只保留通用方法。以下句子为重新编写的示例，不是私人报告或聊天摘录。

## 判断一句话是否值得保留

保留能回答以下任一问题的内容：测了什么、如何处理、为何采用该公式或参数、结果是多少、现象说明什么、误差如何影响结果、题目要求回答什么。

只是在宣布接下来要计算、表示自己已经遵守要求，或重复附近公式和表格的信息，删除。

| 多余写法示例 | 更合适的处理 |
| --- | --- |
| 按照实验手册的相关规定，本次处理将使用电容的实际测量值。 | 直接写实际采用的电容值和单位。 |
| 需要特别说明，全部结果严格依据原始数据计算，未作人为调整。 | 删除，直接呈现数据和计算。 |
| 为进一步提高计算的科学性与准确性，其余组采用同样的方法处理。 | 删除，同类结果合表。 |
| 此处已修复先前的识别错误，避免其继续影响后续计算。 | 正文使用正确读数；必要的更正说明只放交付回复。 |
| 某个内部文件代号的数据表明…… | 按实际含义写材料名称或“第一组演示数据”。 |
| 单凭照片不能充分证明该性能，因此以下结论仅供参考。 | 直接描述可见断口形态，结合实测指标给适当结论。 |
| 各种复杂因素不可避免地给本次实验带来一定误差。 | 写具体因素及影响；没有具体信息就删。 |

“按手册”不是禁词。用户询问规则依据、审核发现条款差异，或方法确实需要来源时，应准确引用。不要机械删除必要的归属说明。

## 简洁不能删掉事实条件

- 电压的有效值、幅值和峰峰值不同；光标间隔可能只有半周期。
- 横梁行程换算或续接得到的应变，不是全程由引伸计直接测得的应变。
- 估计值、直接读数、理论值、拟合值和两种方法的相对差，应使用准确名称。
- 结论只适用于某一范围，就在句中说明范围，不堆叠免责声明。

例如“后段应变由横梁行程增量续接”已交代测量方式，不需要再接一段泛泛的风险提示。

## 讨论写具体因果

写清操作或装置因素、受影响的量和结果变化，不必套固定句式。

- 断后试样未紧密对拢，会使断后标距偏大，进而使断后伸长率偏大。
- 断口最小直径读数偏大，会使断后面积偏大，进而使断面收缩率偏小。
- 声速实验起点附近的间隔偏大，可能拉高拟合斜率；相关系数接近一不排除这种偏差。
- 摆盘附带侧向摆动，会偏离纯扭转模型；应结合观察讨论，不编造操作经历。

用户的小结包含具体经历时优先保留，不改成提高能力、培养精神等通用口号，不替用户虚构体会。

## 批注和全文替换

先确定批注所属文件、页码、选区和句段，使批注、截图与当前源文件对应，不能按旧版坐标猜新版内容。

- 删除一句：只删该句，再修复标点和指代。
- 删至段尾：不越过当前段落。
- 一段仅留指定内容：保留指定内容并重新连贯排版。
- 按用户文字全文替换：保留其措辞，不将旧段落的额外说明加回去。
- 非课程要求则删除：先查本次要求，删除缺乏依据的附加内容。

用户的新更正覆盖前一条歧义解释。修改后检查章节与独立题目是否完整，尤其不能误删后面的讨论与小结。

## 给用户的回复

默认形式是完成情况一句、交付链接、必要差异一句。不复述全部数字，不写冗长工作日志，不以询问是否继续结束已经授权的任务。

用户询问原因、自行计算的方法或要求教学时，解释必要步骤。简短服务于理解，不能以压缩代替说明。
